# Contributing to Jobly

Jobly doesn't accept contributions. Pull requests are closed automatically without review, and
code posted in issues or anywhere else isn't copied in.

You're free to change Jobly for yourself under its [license](LICENSE) (AGPL-3.0, with the
additional terms in [NOTICE](NOTICE)). If you run a changed version for other people, offer them
its source code, and don't call it Jobly.

## Reporting bugs and security issues

Bugs and ideas: [open an issue](https://github.com/aymenoppa/jobly/issues/new/choose). Reports are
read, but there's no promise of support or a reply.
Questions: [ask in Discussions](https://github.com/aymenoppa/jobly/discussions/categories/q-a),
where anyone can answer.
Security problems: please don't open a public issue; see [SECURITY.md](SECURITY.md).
